# Preview notice

This repository distributes a pre-production lab preview for evaluation on
isolated Windows test systems.

- It is not intended for production deployment.
- It is not a replacement for Microsoft Support.
- It does not modify or extend the supported DiagSvc RPC contract.
- Real lab remediation can change the Windows component store.
- Back up or checkpoint the test system before real execution.

The public repository intentionally excludes the core analyzer source,
internal design documents, implementation classes, parser/correlation
algorithms, and private contracts. Operational scripts and packaged runtime
artifacts required to install and exercise the preview are included in release
assets.
